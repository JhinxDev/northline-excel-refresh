# 1.1.0

- Published a separate portable source and download package.
- Replaced the embedded developer folder with an explicit first-run placeholder.
- Removed personal workbook author information, saved printer settings and user-bound Power Query permission signatures. Privacy enforcement remains enabled.
- Made the fixture generator use its bundled CSV by default and omitted internal preservation receipts.
- Added a first-run relocation test and public operator instructions.
- Preserved the sales validation rules, intentional exception fixture and expected totals.

This release does not change the earlier accepted browser demo or simpler sales/inventory workbooks. It adds a separately versioned Excel refresh example.
